# ADR-0070 — 统一学习者大脑：一份有版本的共用判断与对账校准

**Status:** Accepted（设计方向，2026-10-11）；尚未实施。
**Decision source:** owner 2026-10-10 愿景评审「一套多元信号的算法蛮重要——我们之前选 FSRS 有点稀里糊涂的。没有一种长在产品上的大脑的感觉——虽然我知道大概不可能用一个算式表达」；2026-10-11 拍板 B1–B4（决定记录 `/Volumes/YukovalSBak/yukoval-projects/tlp-status/decisions/2026-10-11-supply-and-brain.md`），讨论票转实施。
**Tracking:** [YUK-1470](https://linear.app/yukoval-studios/issue/YUK-1470)。
**Related:** ADR-0066（TypeScript 全栈与实时自适应学习）、ADR-0067（教研白板与事件例会——BKT 删除、白板 finding 防自喂）、ADR-0068（通用学科）、ADR-0028（按知识点 FSRS 调度——其遗忘计算被本文 D4 批准替换）、ADR-0030（by-kind 选题 seam——不在替换范围）、[YUK-1431](https://linear.app/yukoval-studios/issue/YUK-1431)（预测封存）、[YUK-1053](https://linear.app/yukoval-studios/issue/YUK-1053)（同事务结算）、[YUK-1445](https://linear.app/yukoval-studios/issue/YUK-1445)（判分准入）；讨论稿（细节真相源，绝对路径）`/Volumes/YukovalSBak/yukoval-projects/tlp-status/discussions/learner-brain-draft.md`。

## 背景与问题

产品里有好几个「小脑」各算各的：FSRS（`src/core/fsrs.ts`，群体默认参数，评级由判分映射）管「何时复习」；θ̂（`src/core/theta.ts`，Elo）管「出多难」；PFA p(L)（`src/core/pfa.ts`，常数 γ/ρ 从不重拟合）管「会没会」；BKT 夜算零消费者（ADR-0067 D5 已定删除）；EZ 轴不感知更正；mem0 弱点是文字不是证据。审计坐实三个结构性缺口：没有共同的有版本的预测契约（同一知识点知识页与复习页可以各说各话）；没有封存的预测（任何模型都无法证明自己对这个学习者准）；从未做策略评估。同时自信度、提示层级、用时、逐评分点部分分都在采集却无消费者。逐部件现状、审计编号与已采集信号清单见讨论稿 §1–§2。

owner 拍板 B1–B4，把「FSRS + 各算各的」换成一份共用判断 + 统一模型 + 对账。本文是决策记录，不是实施 spec：契约字段全表、信号加权表、融合层公式形状、文献依据以讨论稿为真相源，本文只钉决定与边界。

## 决定

### D1 一份有版本的共用判断契约，所有消费者只读这一份

估计单位是「学习者 × 技能 × 语境」（语境取「任意」即技能整体判断）。契约字段：`p_correct_now`（此刻独立作答的预测把握，附区间）、`retention`（保持与何时跌破目标）、`uncertainty`（区间宽度、有效证据数按独立/帮助/自评分列、部件分歧）、`would_change_it`（最能缩小不确定的下一条证据，确定性算出）、`version`（模型版本、部件版本、输入高水位）、`calibration`（未校准 / 已校准 + 样本对数与对朴素基线之比），以及由确定性模板从上述字段算出的白话档。今日安排、复习、选题、先修门、知识页、Copilot、教研团全部改读这一份；今日口径「一处说法，处处一致」。**契约不含排名、跨人比较、身体与作息数据**（输入校验直接拒收这类来源）。

### D2 组成：记忆 / 能力 / 病（错误模式）三部件 + 按证据质量加权的融合层；数字归代码，解读归 agent

三个各管一件事的部件——记忆（遗忘/保持）、能力（含语境偏移）、已确认的错误模式——经一个 logistic 族融合层（LKT/DAS3H 形状）合成 P(对 | 技能, 语境, 题, 时刻)；每条信号写成带来源 / 独立性 / 判分可信度 / 时点标签的观测，权重 = 该类观测对之后独立作答结果的预测力，起始值为登记在案的先验常数、之后由对账更新（信号清单与起始权重见讨论稿 §2）。**所有数字（P、R、区间、权重、校准、白话档）由确定性代码产出；agent 只读文字**——解读过程瑕疵、给「病」命名、给题打语境标签、提出探针与难度先验，产出以白板 finding 形式提出（`evidence_refs` 只能指向学习事实事件，ADR-0067 防自喂），经「被确认的特征」或「探针结果」才影响数字；agent 写出的解释回读校验，不得与契约字段矛盾。

### D3 对账账本：出题即封存，结算后对账，「长」靠账不靠公式

凡是正式出题（练习、复习、定位、帮助后检查、考前），都在出题事务内把当时的契约读数写成一条封存预测事件（写在事件脊上，不另建总线）；结算后与独立结果配对对账，判分被更正时对账跟随有效判分。个人校准映射与证据权重从对账记录中学：权重一变即模型版本变，附一行白话变更说明、可回滚。教研团每周盘点附校准表（封存条数、对数损失是否变好、哪些格子还「不知道」），没有变好就写没有变好。

### D4 B1：FSRS 现在就替换为统一模型的遗忘项——owner 对 §9 承重能力的明确替换批准

owner 原话：「我觉得一个卡片记忆管理不合适了，需要新模型。」讨论稿推荐的「FSRS 保留为记忆部件、调度不变」（§3.3 选项 A）被否决：**遗忘计算现在就换成统一模型的遗忘项**，知识点级调度单元、到期列表与结算入口延续。

本节即 AGENTS.md「删除、替换或降级 rewrite-prep §9 的 8 项 pre-AI 承重能力，须 owner 明确批准」规则下，对第 1 项中「确定性 FSRS 调度」的**明确批准记录**（2026-10-11）；同项的「按 kind 确定性选题 seam」（ADR-0030）不在替换范围。随之，YUK-1470 描述里「任何替换方案必须先封存对账证明更准才可上线」一条**对遗忘部分不再适用**——替换经 owner 直接批准执行；该挑战者证据门槛仍约束 D7 的能力部件切换与其余一切挑战者。

替换带三条 owner 已认的技术安全，缺一不切换：

1. **TEST 调度验证**：新遗忘项接管前，在 TEST 上证明调度可用——到期列表、今日兜底、结算都能正常运转；
2. **确定性兜底**：模型不可用时走确定性兜底，练习流永远不依赖模型在线（与 ADR-0067 硬边界 2 同构）；
3. **群体先验起步**：没有真实数据前，遗忘参数从群体先验出发，并如实标注 uncalibrated。

### D5 B2：纠正立刻生效 + 一次可跳过的轻量独立检查

用户的更正立即对显示与安排生效（硬约束，不悄悄推翻——后续证据与更正冲突时把冲突摆出来请用户再看）；同时安排一次可跳过的轻量独立检查，其结果只用来校准「你的自我判断」这项信号的权重，不推翻纠正本身。事实更正（判分申诉）仍走现有 Judgment 重放。

### D6 B3：约 100 次对账 + 赢过朴素基线 + 按技能×语境样本够，才显示数字

owner 未采纳推荐的 300 对，门槛定为**约 100 次**「封存预测 → 独立结果」对账；达标还须在对数损失上赢过朴素基线（该技能近期正确率），且只在样本够的那些「技能 × 语境」上显示——其余地方继续只给白话和证据。更快出现的数字更抖，由后两道闸兜住。白话在前、数字下钻；排名根本不计算。

### D7 B4：θ̂/PFA 经挑战者流程合成一个能力部件；BKT 夜算删除

现役 θ̂ / PFA 是 §9 第 2 项「掌握度 base 层」的现役实现，不直接重写：统一能力部件作为挑战者在影子里写封存预测，按预注册指标（对数损失改善、校准不变差、配对 bootstrap）胜出**且 owner 批准后**才切换，旧实现退为对照；部分分、帮助折扣、语境偏移并入，离散贝叶斯网格（`src/core/theta-grid.ts` 暗轨）在此有了用途。个人 FSRS 参数、网格后验、任何新预测部件同走挑战者流程。**BKT 夜算零消费者，按 ADR-0067 D5 删除**；EZ 速度/谨慎留作描述不进 P(对)。

### D8 Owner 已固定、不可重开的边界

白话判断在前、数字与证据下钻；不算排名（根本不计算）；身体与作息数据永不接入（契约输入拒收）；错误模式（「病」）由系统命名；蒙对只算弱证据（与自信度、用时组合承担 BKT 的 guess/slip 角色）；结果分与过程瑕疵分是分开的字段——过程瑕疵不改结果分，是「病」与「对得不稳」的证据。

## 硬边界（后果）

1. **§9 承重的唯一让渡即 D4**：第 1 项「确定性 FSRS 调度」经 owner 明确批准替换为统一模型遗忘项；替换后调度仍必须确定性可复算、模型不可用时兜底可用——「不依赖模型在线」的语义不降级。其余七项承重不动；D7 的能力部件切换另需 owner 批准，批准前现役 θ̂ / PFA 原样运行。切换 PR 同步更新 rewrite-prep §9 第 1 项措辞与 ADR-0028 状态行的对应关系。
2. **确定性兜底不可降级**：统一模型缺席/失败时，今日安排与复习回落确定性兜底，练习流永不依赖模型可用。
3. **不出现第二事件总线**：封存预测事件写在事件脊上（ADR-0067 D1）；契约是版本化的读取面，不另建平行存储总线。
4. **学习者可见面在 D6 门槛达成前不出现任何新数字**；数字只在下钻里，白话档在前。
5. **身体/睡眠/作息永不进入；排名根本不计算**——契约层直接拒收、直接不提供。
6. **agent 不写数字**：所有数值与白话档由代码产出；agent 产出是白板 finding，只能经确认特征或探针结果影响数字（防自喂）。

## 分阶段交付（对齐 AGENTS.md 交付阶段）

1. **帮助靠谱（W1）第一刀**：契约 v0 只读适配（从现役 θ̂/PFA/FSRS 原样读出字段，`version=v0-incumbent`、`calibration=uncalibrated`，不改任何计算）；出题即封存（v0 的 P(对) 与复习项 R(t)，结算后对账、更正跟随有效判分）；Copilot 学情头改读契约（今天它不读同一知识点的遗忘）；作答账本补字段——结果分与过程瑕疵分分开记、「蒙的」标记、提示深度、有效用时（只记录不改数值）。验收：封存先于结果可见、时序可证；更正重放后对账仍一致；学习者看不到任何新数字。
2. **紧接第一刀：遗忘替换（D4）**——TEST 调度验证 + 确定性兜底 + 群体先验起步，然后接管调度。
3. **说清不知道并检验（W3）**：白话档与四问解释（我觉得你怎样 / 凭什么 / 哪里没把握 / 什么会改变我的看法）上线；能力挑战者（θ̂/PFA 合一）在影子跑；证据权重与个人校准开始学习、达 D6 门槛前只写不用；BKT 夜算随本阶段删除。消费者逐面改读契约（选题、先修门、到期列表、知识页）与「病」对象、「意外」触发的完整迁移表见讨论稿 §6.2。

## 被拒绝的备选

- **FSRS 保留为记忆部件、调度不变，只把 R(t) 进契约对账（讨论稿推荐 A）**：owner 否决——「一个卡片记忆管理不合适了，需要新模型」；替换现在执行（D4，含三条技术安全）。
- **维持现状各算各的（选项 C）**：正是 owner「稀里糊涂」「没有长在产品上的大脑」的不满本身。
- **现在就重写 θ̂/PFA 为一个能力部件（B4 选项 B）**：碰 §9 base 层且零对照证据——走挑战者流程，赢了且 owner 批准才换。
- **显示数字门槛 300 对（讨论稿推荐）**：owner 定约 100 对；速度换来的抖动由「赢朴素基线 + 按技能×语境样本够」双闸兜住。
- **纠正只作一条强证据、由模型综合决定（选项 2C）**：违背「纠正生效」的硬约束——被 D5 取代。
- **深度知识追踪模型**：公开数据上并不优于简单 logistic/IRT 族，且不可解释、n=1 难用、不能确定性复算（讨论稿 §3.5 文献）——融合层选 logistic 族。
- **LLM 直接出数字**：微调后约与标准 BKT 持平、校准无证据——LLM 只读文字、只提 finding。

## 未决问题

- 统一遗忘项的具体函数形态与参数个数（指数衰减族 vs DASH 类带练习历史的遗忘项）：以「群体先验可立即起步 + 确定性可复算」为约束随第一刀选定；FSRS 是否适用于「知识点应用」本身也无证据，替换后同样要对账。
- 「有效用时」的定义（I01-M017：离开屏幕不等于在思考）未解决，用时权重默认 0。
- 「意外」触发阈值、各信号起始权重均为登记在案的工程初值，待对账修正。
- n=1 统计力有限：约 100 对是全局总数，多数「技能 × 语境」格子会长期「还不知道」——这是诚实结果，靠语境向技能整体收缩借力。
- 契约的物化形态（读取时重算投影 vs 物化快照 + 高水位）与封存写入的墙钟成本，随第一刀实测定。
- 学习收益本身仍未知：大脑更准 ≠ 学得更好，须到「证明有效」阶段以真实使用回答；所有权重与门槛在真实使用前都是预注册假设。
