# ADR-0068 — 通用学科：共同维护的学科语境与证据准入的能力

**Status:** Accepted（设计方向，2026-10-10）；尚未实施。
**Decision source:** owner 2026-10-10 21:45「学科我的希望是能够完全 general，由人与 ai 共同维护 context。」
**Tracking:** [YUK-1452](https://linear.app/yukoval-studios/issue/YUK-1452)。
**Related:** ADR-0066（TypeScript 全栈与实时自适应学习）、ADR-0067（教研白板与事件例会）；[YUK-1434](https://linear.app/yukoval-studios/issue/YUK-1434)（学科合同与诚实状态）、[YUK-1445](https://linear.app/yukoval-studios/issue/YUK-1445)（判分准入地基）、[YUK-1404](https://linear.app/yukoval-studios/issue/YUK-1404)（录入结构化）、[YUK-1448](https://linear.app/yukoval-studios/issue/YUK-1448)（题库即题源）、[YUK-1449](https://linear.app/yukoval-studios/issue/YUK-1449)（教研白板）；设计草案（细节真相源，绝对 artifact 路径）`/Volumes/YukovalSBak/yukoval-projects/tlp-audit-artifacts/yuk1388/stage4/final/general-subjects-design-draft.md`。

## 背景与问题

今天加一门学科要改代码。语文、数学、物理三门「内置学科」各自是一摞 TypeScript 文件（`src/subjects/<科>/profile.ts` + `skills/*/SKILL.md` + 种子）；管理页虽然能「新建学科」，但建出来的只是名字外壳——审计实测其六条规则绑定全部指向「通用」默认值，没有自己的题型、判分路由、出题规范和题源（YUK-1388 第四批审计：S13-A11、S12-01 CONFIRMED）。学科能力由**代码里有哪些目录**决定：英语、化学、生物、历史、地理、政治、信息技术全无 profile。学科说明（SKILL.md pack）确实是模型输入，但住在磁盘文件里，owner 在产品里看不见、改不了（S13-A08；owner 体验 O6）。外部题源覆盖写死在代码里：jyeoo 只覆盖高中 10–12，初中/大学 `out_of_band` 静默跳过（S14-V6 CONFIRMED、HC-41）。文科主观题无可执行量尺、无教师校准（I01-M064）。证据清单见草案 §1。

同时「学科」底子是对的：SubjectProfileSchema 是数据形状而非代码分支；subject 控制行 + 六 trait + 双 journal 已在 DB 且有活 consumer；判分路由结构优先、学科偏好其次；D17 准入合同与发题闸现成。问题不在方向，而在三点：①配置内容散在代码 profile、磁盘 SKILL.md、DB trait 三处，owner 只能改到第三部分；②「会什么」靠声明不靠证据；③新学科没有从「名字」到「能判」的坡道。

本 ADR 是决策记录，不是实施 spec：语境十节（C1–C10）的字段形状、触发器表 E1–E8、keep/generalise/retire 逐对象映射表、风险与否决条件等细节以草案为真相源，本文只钉决定与边界。

## 决定

### D1 学科 = 学科语境（数据）+ 能力矩阵（证据派生）

> **学科 = 一份学科语境（subject context）+ 一张能力矩阵（capability matrix）。**
> 语境是人与 AI 共同维护的数据，回答「这门课是什么、怎么教、怎么判」；
> 能力矩阵是只读的证据派生物，回答「现在真的能干什么」。
> 语境可以起草得很满，能力矩阵只按准入证据点亮——两者并排显示，永不混淆。

语境存 DB、有版本、有来源徽标、可撤回；它喂给模型当提示、喂给路由当偏好、喂给页面当显示。能力是代码 + 证据：判分执行器、出题门、调度器是注册表里的已验证 runner；「这门课能判题型 X」是准入实测的事实，不是语境里的勾选。**新增学科 = 新增语境 + 逐格点亮矩阵，零新代码**；需要新代码的只有一种情况——出现现有执行器结构上判不了的新答案形态（如「编程题需运行测试」），那是能力层扩展，按既有 capability 注册流程走，与学科语境解耦。

语境分**操作层**（机器消费的紧 schema 字段，喂路由与闸门，zod 写门守门）与**叙述层**（人与模型消费的带版本文档，喂 prompt 与人读），两层同店同版本；十节划分见草案 §2.2。

### D2 复用现有学科控制面为存储，不建平行存储

学科身份用 subject 控制行 + subject_name_claim；操作层配置用现有 trait/装配链（迁移期）→ 终态每科一份完整有效配置 + revision + append-only 历史（S13-A09 替代方向，builtin 降为默认模板）；叙述层是同一学科存储的版本化文档槽（journal 快照沿用 subject_trait_journal 先例）；版本与并发用 revision + CAS + 控制面 advisory lock；能力矩阵是从 admission 事实 + 出题门结果派生的**只读投影**，每次重算，不手写。**不新建**：第二套学科表、第二份 profile 写者、独立文档系统、第二套版本轴、新巡检器（夜间体检扩展现有 subject_profile_audit_nightly）。这是 ADR-0067 D1「不建平行总线」在学科域的同一条红线。

版本与溯源三种来源、三种徽标：owner 手写（现有写面，CAS + journal）；AI 提议、owner 确认（proposal 落库时 journal detail 挂 `drafted_by: 'agent'` + proposal id + 证据引用，**不新增 actor 枚举**）；证据派生（只读投影，不进 journal、不需确认）。更正协议免费获得：证据原件被更正时，引用它的提议失效，已生效语境节显示「依据已撤回，建议复核」。

### D3 能力只能由准入证据点亮（per subject × answer class）

一门学科「能判题型 X」的充要条件，全部可机检：

1. **声明**：语境 C3 有 X 的结构描述（嵌套 × 排版 × 答案语义）。
2. **有执行器**：X 映射的 answer-class（结构优先）有可运行 runner；确定性比较器天然满足，model_executor 还需 (3)。
3. **有准入证据**：该（subject × answer-class）的 AI solve+judge 切片按 D17 门槛实测通过——zero-failure、holdout ≥30、per-criterion 达预注册阈值，封存版本/输入输出摘要/task-run/费用（YUK-1445 主路径既定做法）。
4. **出题同源**：quiz_gen 在同一切片过 kind_conformance + solve-check。

切片 id 携带学科与判分类范围（如 `slice_<subject>_<answer_class>_v<n>`）；issuer 闸（`auto_score` 要求 admitted）不变。**名字不产生能力**（S13-A11）：能力矩阵是唯一声称面，页面上任何「能判」字样必须点得到对应准入证据。**判不了就不出**：无 admitted 执行器的题型不进冷启动/定位/今日练习，诚实显示还差什么（YUK-1445 红线全科化）。文科主观题的准入证据要含与教师标准的 QWK 校准；无本人教师数据时标 `uncalibrated`，不冒充已校准。

### D4 AI 提议走 ADR-0067 白板，生效路径分级 L0–L3

AI 永不直接写学科语境。学科语境类提议是 ADR-0067 白板 finding 的一种 kind（`subject_context`），proposed_action 指向具体语境节；触发器表 E1–E8（录入出现语境外题型、判分申诉成模式、新大纲材料、教师批改回流、路由频繁降级、准入出结果、题源覆盖变化、owner 口头修正）见草案 §3.1，全部是带终态 job + 登记在案的确定性阈值参数，模型不改阈值。生效路径分级：

| 级别 | 适用 | 路径 |
| --- | --- | --- |
| L0 派生事实 | 能力矩阵、覆盖率、带内/带外 | 无提议，投影重算，页面直显 |
| L1 低风险可撤回 | 术语条目、错法观察笔记、大纲摘要文字、题源覆盖显示 | 自动生效 + 学科页留痕 + 一键撤回 |
| L2 owner 确认 | 判分路由偏好、量尺指引、题型增删、题源白名单、考试风格、教学风格 | proposal + 确认 + 可撤销 |
| L3 owner 明确批准 | 任何触碰规划文档 §9 八项承重能力语义的改动 | 未批准只降级不生效（V01-F07） |

防自喂纪律沿用白板稿：提议的 evidence_refs 只能指向学习事实事件，不得指向另一条提议的文字；语境类提议不推给学习者，只在学科页待确认区出现（S13-A63 保留项）。语境变更生效后**回读验证**：例如 C3 改了判分偏好，回读 route-resolve 对新题型的实际解析结果确认生效——没有变化即失败，不报成功。

### D5 新学科 bootstrap：从一句话或一张照片到能练

流程全部是现有机制的组合，唯一新增的是「起草」这个 AI 任务与学科卡页面：

1. **命名**：owner 输入「信息技术」→ thin-create 薄壳（控制行 + claim + 默认绑定 + 知识树根 event-sourced），能力矩阵全灰。
2. **起草**：owner 给一句话描述（学段 + 考试目标），或拍教材目录/考纲/一份卷子；AI 读材料起草全部语境节为一个待确认 proposal 包（必须带 evidence_refs，不允许凭空写），学科页逐节确认/改。
3. **首批录入**：走 YUK-1404 结构化链；词表外的题型进 E1 触发器。
4. **准入跑**：该科 gold 小集上跑 AI solve+judge 实测 → D17 证据 → 能力矩阵逐格点亮。
5. **诚实状态全程在线**：每一格显示「能/不能 + 依据 + 差什么」。

**第一天最低承诺**：新学科第一天能录材料、长知识树、做笔记、讲解、练客观题；主观题判分在准入前不出。不承诺未实现能力，差别只在：现在它有一条看得见的坡道。

### D6 SKILL.md 内容保留、只换容器，注入等价为验收

SKILL.md 正文真的进模型（S13-R01「从未通电」已 REFUTED：resolver 读磁盘正文 → `ctx.piSkillDocs` → system prompt，消费点清单见草案 §1.1）。处置是**内容保留、容器更换**：出题/验题规范正文（math/physics/yuwen 各 pack，含 references/anti-patterns/rubric）迁入语境叙述层 C8，注入键从 `<subject>--<pack>` 命名空间平移到语境文档 id，消费点不变；few-shot 范例内容零丢失为硬约束（迁题库范例标记 vs 语境附件未拍板，见未决问题）。验收 = **注入内容逐字等价**：先双跑对比等价，再切消费点，最后才退役磁盘包与 resolver；等价验证之前磁盘包一个不删。

### D7 来源覆盖诚实声明

外部题源覆盖从代码常量变为来源节 C7 的**声明字段**：producer 注册时声明自己的语料范围（学科 × 学段），需求侧按声明过滤。当前唯一 producer jyeoo 只覆盖高中 10–12；初中/大学不再静默 `out_of_band`，学科页与供题计划诚实显示「外部题源暂缺，走自有材料 + AI 出题」（S14-V6/HC-41 修复方向）；「学段 → 课程范围」的通用轴放 C1，jyeoo 的 10/11/12 只是该 producer 的声明值。四条题源线（本人材料、教材笔记、外部题源、AI 生成）全部学科中立，AI 生成与外部题走同一准入门（YUK-1448 验收 3、YUK-1445）。

## 硬边界（后果）

1. **8 项 pre-AI 承重能力不削弱**（`docs/planning/2026-10-07-ts-migration-and-ui-rewrite-prep.md` §9）：FSRS 调度与选题 seam、掌握度 base 层与 calibration、统一题库与不可变 Judgment、OCR 确定性抽取、提议 + 确认 + 撤销、pedagogy 确定性 shortlist 与 today 兜底、运行日志与费用账本、housekeeping cron 语义。任何删除、替换或降级需要 owner 明确批准。
2. **确定性判分器保持通用代码**：五个比较器（exact_option_set / exact_text / numeric_tolerance / numeric_unit_conversion / exact_matching_pairs）、answer-class 轴、判分路由解析器、出题合同闸、D17 准入合同与发题闸全部学科中立——不进语境、不 per-subject 化、不需要逐科准入（确定性比较器全科通用）。
3. **作文与主观题判分标 uncertain**：在教师量尺校准证据（QWK 达预注册阈值）之前一律 `uncalibrated`，不冒充已校准（I01-M064）；「AI 从未在高中题目失手」是针对特定模型在高中的经验，不外推到任意学科与当前生产模型。
4. **能力矩阵是唯一声称面**；不出现第二套学科配置写者、第二条 prompt 注入通道（验收项）；语境改动影响判分必须有 journal 记录且可撤回。
5. **迁移丢 prompt 内容是硬红线**：SKILL.md 内容在迁入叙述层并双跑验证注入等价之前不删（S13-A08 保留项）。
6. **与 AGENTS.md 边界的关系**：现行规则「`core/` 只放跨科目逻辑；科目专属逻辑留在 `subjects/<name>/`」的本意（科目专属逻辑不进 `core/`）保留并强化；变化是**科目专属知识**（题型表、判分偏好、出题规范正文等）从 `subjects/<name>/` 代码移入学科语境数据，`subjects/<name>/` 代码收缩到映射表保留项（默认模板、zod 形状、fixtures、`_shared` 结构描述符框架）。AGENTS.md 该行随本 ADR 做最小措辞更新，见同一 PR。

## 科目专属代码处置（后果）

不复制映射表：keep（原样保留，语义不变）/ generalise（机制保留并泛化为语境驱动）/ retire（内容已迁出或从未有消费者；先 census/drain 再删）的**逐对象映射**——profile-schema、registry、六 trait 写门与装配链、水合链、控制面锁、管理写面、thin-create、夜间审计、各磁盘 SKILL.md 包、few-shot、语文 curriculum seed、判分 runners、供题链、磁盘 skill resolver 等——**以草案 §8 映射表为真相源**。凡碰八项承重能力的删减需 owner 明确批准（V01-F07）。

## 分阶段交付（对齐 AGENTS.md 交付阶段）

1. **第一天能用（W0 同波，在修）**：本设计不加学科面新功能。YUK-1445 判分准入地基（AI solve+judge 按金标实测准入；判不了的题不出）与 YUK-1404 录入结构化先行——它们先于一切学科工作。
2. **帮助靠谱（W1）**：学科卡 v1——能力矩阵只读投影（从 admission 事实派生）+ 现有 trait 编辑的白话分组；「新建学科 → 外壳 → 诚实状态」可用；题目级「为什么还不能练」可见。
3. **按真实时间安排（W2）**：共同维护回路 v1（E1/E2/E3/E5 触发器上线，L1/L2 生效路径接通 proposal/确认/撤回）；来源覆盖声明字段落地，jyeoo 带外不再静默（S14-V6 修复）；学科语境白板 finding kind 上线（随 ADR-0067 W2 波）；**SKILL.md 内容迁移在本阶段完成**——内容保留、容器更换、双跑注入等价、消费点切换、磁盘 resolver 随之退役。协调裁定：该迁移不依赖真实使用，owner-scope 的完成不等待它；逐科真实使用评估仍留在后续阶段。
4. **说清不知道并检验（W3）**：全节 provenance 徽标（owner / AI 提议 / 系统算出）+ 依据链接；准入切片按（subject × answer_class）铺开；`uncalibrated` 等未知状态显式标注；语境变更回读验证成为生效必要条件。
5. **证明有效（W4，YUK-1434 波）**：逐科真实输出盲核（预注册真实复杂题目小集，出题→作答→判分→帮助端到端实测）；文科主观题 QWK 教师量尺校准；教师接力包回流（YUK-1435 联动）；六 trait → 每科一份完整配置（S13-A09）与大合同瘦身（S13-A07）。新学科声称「可判主观题」由准入证据解锁，不由日历阶段解锁。

## 被拒绝的备选

- **每新增学科写一套 `subjects/<name>/` 代码（现状）**：能力由目录决定，名字 ≠ 能力（S13-A11、S12-01）；被 D1「语境 + 证据矩阵」取代。
- **新建一套「上下文文档」存储 / 第二份 profile 写者**：双写漂移、更正协议重造，是 ADR-0067 明令禁止的平行总线学科版；被 D2 复用控制面取代。
- **能力由语境勾选声明**：会腐烂、「名字即能力」回潮；被 D3 证据准入取代。
- **AI 直接写学科语境**：判分语义不可追溯、不可撤回；被 D4 提议 + 分级生效取代。
- **新学科先跑完准入才开始学**：主观题判不了不阻塞录题/笔记/讲解/客观题练习；被 D5 第一天最低承诺取代。
- **迁移时直接删磁盘 SKILL.md 重写 prompt**：未测真实输出前不说内容无价值（S13-A08 保留项）；被 D6 注入等价验收取代。
- **外部题源覆盖继续硬编码 + 静默 `out_of_band`**：Welcome 收集的学段被供题链静默跳过；被 D7 声明化取代。

## 未决问题

- **跨学科判分质量全部未知**：语文文言、数学、物理之外没有真实输出证据；YUK-1445 已把「先实测当前生产模型判分准确率」列为前置，作文与开放作答尤其难（I01-M064）。
- **叙述层注入形态未定**：现状整篇正文进 system prompt；语境节变多后整篇注入 vs 按需检索的成本/质量权衡未测，迁移第一步保持整篇注入等价，检索化是单独优化评估。
- **few-shot 范例归属未拍板**（题库范例标记 vs 语境附件）；检索路径改造量未估，硬约束只有内容零丢失。
- **学段轴建模未拍板**：「初中数学/高中数学」是同一学科 + C1 学段段还是两个学科实例（建议前者），无真实使用验证；大学课程覆盖完全未知。
- **非纸笔学科**（编程需跑测试、听说需音频、实验学科）结构上超出现有执行器的答案形态：本设计只保证这类学科可「先语境、后能力、诚实显示」，不承诺时间表。
