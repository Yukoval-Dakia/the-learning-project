# YUK-1112 — pi 1.0 upgrade

Owner requested the latest pi core on 2026-10-03. Registry latest stable is 1.0.0
for both pi-agent-core and pi-ai (previously 0.85.1); pi-telemetry follows 1.0.0.
The formerly closed 0.87.1 dependency PR is not reopened or force-updated.

Two API migrations are required. finishTurn returns an action, replacing
shouldStopAfterTurn's boolean. System prompts and tool declarations now live in
system-role transcript messages instead of AgentContext.systemPrompt. Both root
and nested loops are migrated. convertToLlm preserves system messages; compaction
replays system deltas before trimming conversation history and reserves space for
instructions, tool declarations and the learner context.

A shared limiter ends the run at maxTurns before polling queues. A clean final
answer is success even at maxTurns=1; a tool-call turn at the ceiling reports
error_max_turns. Provider error/abort remains error_during_execution instead of
being relabeled by the cap. Caller abort/close retains no-terminal-frame semantics.
The same clean-answer rule fixes the former unconditional child ceiling failure.

Real-engine regression also exposed an existing cost defect: terminal usage read
only the root's final response. It now sums all root responses in agent_end's
invocation messages and then adds child usage, excluding durable replay history.
This matters because downstream lifecycle treats terminal usage as authoritative.

Validation includes the installed agentLoop with only provider streams scripted:
request counts, real tools, nested loops, ceiling/queue handling, provider errors,
caller abort, replay, skills, tool declarations, compaction, token/cost totals.
A loopback HTTP test exercises the real MiMo Anthropic-compatible provider/client
through two SSE responses and asserts request system text/tools/tool result and
terminal token totals. It makes no external or paid model requests and does not
establish model output quality. Existing actual-output evidence remains historical.

PR #1522 supplies the independent shared schema/dependency gate repairs (YUK-1111,
YUK-1115). Do not claim the upgrade merged/deployed before exact-head CI and the
required review/waiting window finish. No production deployment is included.

Local acceptance: 160 scoped tests across ten files passed, including 11 installed
engine/HTTP regressions; typecheck, lint ratchet (299 warnings), production build
and all documented pre-PR audits passed. Independent initial review found no
P0/P1 and separately ran 88 adapter/engine/Responses/subagent/hooks tests.
