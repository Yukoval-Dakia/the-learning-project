### Reentry cause and repair

Parent's `/tmp/yuk1047-closeout-runtime/REPORT.md`, `acceptance.json` and `first-run-reopen-failure.json` show that API/SQL held the final ACKed bytes and epoch while same-page reentry showed the older draft or empty input. The inspected source explains the result: ACK updates only the mounted component's `draftEpoch`; on a later mount, `frozenQ` supplies its previous QueryClient snapshot, hydration sets `hydratedIssuance`, and the eventual fresh GET cannot hydrate that issuance again.

The real QueryClient regression retains one client across actual PfSolo mount/unmount, holds the real HTTP seam's save ACK, then delays the reentry GET. Both empty and older cached draft cases first failed after the QueryClient had received the new epoch while the textarea still held stale bytes. The fixture has two response slots, a pinned public passage, original image evidence with explicit scoring-unit targets, long multiline text, nested-looking original text, combining marks and final emoji bytes. The new mount now requests a fresh issuance read and restores once after that read succeeds, before opening the editor. The existing one-time hydration protection continues to prevent background reads from replacing current local edits or advancing their CAS epoch. A failed reentry GET cannot open cached input as the new editing baseline. Accepted submission bytes take precedence over a leftover live draft, including submissions whose judgment is pending.

### P1: return/save and submit mutual exclusion

PfSolo now exposes returning state for the existing controls and keeps an immediate ref guard for handlers. Return waiting disables answer editing, submission and attachment controls; judge and commit handlers reject competing actions. Autosave stays enabled while returning, so A's ACK advances the epoch and the chain sends B before exiting. A failed final save releases the returning controls and keeps input for retry. No shared hook disabled semantics changed. GREEN holds the final B ACK, proves no advice/upload starts, checks B uses A's acknowledged epoch, and observes exit only after the final ACK.
