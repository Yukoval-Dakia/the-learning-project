## Proven remaining acceptance gaps and bounded owner seams

1. **All three surfaces still belong to the old SPA at this baseline.** The baseline router/page evidence above is the old client route tree; current checkout’s changed files are only `/mistakes`/docs. No evidence in this scoped investigation establishes Start mounting, a real Start browser flow, Start authorization continuation, or replacement of these SPA consumers. Keep these rows open until the owner’s Start integration proves `/`→`/today`, direct `/today` and `/inbox`, refresh/deep navigation, auth behavior, and old-SPA consumer/build/static-fallback exit.
2. **The scoped unit/DB tests do not prove new-front-door behavior.** Existing handler DB and mocked UI tests cover useful contracts, but there is no evidence here of Start browser acceptance against the actual assembled routes/DB for these pages or of old-entry exit. Do not promote tests or the 1376 `/mistakes` evidence to those claims.
3. **Today is broader than its top-level component.** Port the embedded TeachingBrief, conjecture, probe, recent AI changes, notes board, cost ribbon, active-goal ProfileBand read, and LearningIntentComposer proposal command as consumers. Their reads and commands must retain the existing typed operations/domain seams. Preserve opt-in/failure states because the direct `TodayPage` test file is narrower than the rendered route.
4. **Existing seam to retain:** the Today summary is already one typed aggregate, but its due KPI internally calls a `Request`/`Response` handler (`shell/server/workbench-summary.ts:66–78`). Reuse the current operation for the W1 migration; record this as an existing coupling to clean only if the main owner’s broader Start/API boundary requires it. This observation is source-proven, not a claim of a current correctness bug.

No substantive runtime defect was established by this inventory. Recommendations are bounded to consumer replacement and behavior-preserving operation reuse; no new function, harness, recovery mechanism, or design change is proposed.
