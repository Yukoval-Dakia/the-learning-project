#### [ADR-0054 §1 / ADR-0060 Decision] Copilot 会话续接与压缩仍以 Claude Agent SDK 机制描述
- **声明**: ADR-0054「Foreground consecutive POSTs resume one Agent SDK session」；ADR-0060「显式启用 SDK `autoCompactEnabled`，经 `Options.settings` 关闭预压缩，runner 追加 `SessionStart(source=compact)` hook」。
- **代码**: `src/server/ai/pi-agent-adapter.ts:25,820`——唯一执行引擎已是 `PiAgentAdapter`（YUK-921/1025，SDK 已退役，`package.json` 无 `claude-agent-sdk`）；压缩改为 `nativeCompaction → transformContext` 预算裁剪 + 自研 `compact_boundary` 帧；续接为 `pi:` 前缀 id + 本地消息回放（`src/server/session/conversation.ts:270-305` 仍沿用 `agent_sdk_session_id` 列名）。代码内已无 `autoCompactEnabled`。
- **冲突**: ADR 描述的 SDK 机制（server-side resume、SDK 原生 auto-compact、SessionStart hook）在代码中不存在，行为等价性由 pi 适配器自行保证，ADR 无 supersede 标注。
