# YUK-1028 — GPT-6 Astra P2: 费用归因、缓存与逐次调用预算闭合

> Status note: owner paused P2 on 2026-09-23 (PLAN.md) — this brief is restart-ready, pending owner authorization (see `needs-info` recommendation in triage-report.md).

## Agent Brief

**Category:** enhancement
**Summary:** Close the cost-accounting and per-wire budget gaps for the new `openai` (gpt-6-astra) lane so Astra can be metered like every other provider before any task is switched to it.

**Current behavior:**
- `resolveAttemptCostTruth` (`src/server/ai/attempt-cost.ts`) already classifies `opencode-go`/`openai` pi-catalog lanes as `basis:'estimated'` (pi `usage.cost` is a rate-card estimate, not an invoice). This part of the original ticket is already done.
- `src/server/ai/pricing.ts` has a local pricebook (`localCostUsd`, `hasLocalPricing`, `ATTEMPT_PRICEBOOK_VERSION`) used for xiaomi estimates — but has **no OpenAI/Astra entry**, so an OpenAI attempt with missing/unknown usage falls back to `unknown` instead of a local estimate.
- pi-ai 0.85.1 already reads `cached_tokens`/`cache_write_tokens` from usage and deducts them from `input_tokens` — double-counting is a risk if pricing code re-deducts them.
- There is currently **no per-wire/per-call budget enforcement** for the Astra lane (the old `maxBudgetUsd` Option was removed in YUK-1025 P4; only `task.maxCost` metadata exists, which is not an enforceable reserve/settle).
- Astra pricing (official): standard input $10/M, cache read $1/M, cache write $12.5/M, output $50/M; requests with input >272K switch to $20/$2/$25/$75 for the **whole request**.

**Desired behavior:**
- OpenAI-local cost estimation exists with `basis:'estimated'` and a versioned pricebook ref (pricebook version + model + service tier), correct across the 272,000/272,001 boundary, cache-read/cache-write buckets, and reasoning-inclusive output tokens.
- Root and child (subagent) attempts are costed once each — no double counting on the shared run.
- Attempts whose usage is missing/unreadable still record `basis:'unknown'` (never `0`); historical ledger rows are not rewritten.
- Per-wire budget closure: before a paid call, an approved per-task/run budget is atomically **reserved** through the existing attempt/lifecycle owner (Postgres, transactional, shared across API/worker and root/child); on terminal settle the reserved amount is reconciled against the actual cost. Cancellation or lost-usage does **not** auto-refund. The mechanism must survive concurrent attempts and queue redelivery.
- Existing timeout/turn-cap semantics are unchanged; only the budget/cost surface changes.

**Key interfaces:**
- `resolveAttemptCostTruth` / `AttemptCostTruth` (src/server/ai/attempt-cost.ts): classification behavior for `openai` provider — extend, don't regress.
- `localCostUsd` / `hasLocalPricing` / `ATTEMPT_PRICEBOOK_VERSION` (src/server/ai/pricing.ts): where the Astra pricebook entries go (272K tier boundary must be pure-computable and unit-tested).
- `AiRunLifecycle` / `provider-attempt` owner (src/server/ai/run-lifecycle.ts + runner/lifecycle): the seam where reserve/settle must be transactional; unknown cost stays unknown.
- `PiAgentAdapter` (src/server/ai/pi-agent-adapter.ts): where usage/cached_tokens are already extracted — verify no re-deduction downstream.

**Acceptance criteria:**
- [ ] `resolveAttemptCostTruth` returns `basis:'estimated'` with a `pricebook:` ref for `openai/gpt-6-astra` attempts when usage is present, and `basis:'unknown'` (not `0`) when usage is absent.
- [ ] Pricing math at the 272,000/272,001 input-token boundary is covered by pure unit tests (whole-request tier switch, not per-token).
- [ ] Cache-read and cache-write token buckets are priced at their own rates and are **not** also counted as input tokens.
- [ ] A budget reserve/settle path exists through the existing attempt/lifecycle owner, is transactional, is shared across API+worker and root+child attempts, and does not auto-refund cancelled/lost-usage attempts.
- [ ] End-to-end DB test: a run that produces an attempt + ledger entry can be reconciled to the correct `estimated`/`unknown` basis without double-counting.
- [ ] Existing retry/timeout/cancellation semantics unchanged (no new transient layer introduced).
- [ ] Scoped unit + DB tests, `pnpm typecheck`, `pnpm lint`, `pnpm build` green.

**Out of scope:**
- Rewriting historical cost rows or backfilling old attempts.
- Extending the budget mechanism into a general billing platform or changing subscription accounting.
- Flipping any task to Astra (that is P3 / YUK-1029, owner decision).
- Changing provider auth, wire protocol, or the model catalog.
- Real paid calls (require separate per-call budget authorization).
