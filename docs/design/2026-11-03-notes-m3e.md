## 做了什么

- **外壳**：两页都用 `<UiNextRoot className="nt-page">` 加 `<main className="… un-m3e-bridge">`，做法同题库页。样式都限定在 `[data-ui-next].nt-page` 下，颜色走 M3 角色（通过 `.un-m3e-bridge` 映射 `--un-*`）。
- **换掉的旧件**：`Btn` / `IconBtn` / `LoomIcon` / `EmptyState` / `ErrorState` / `SkLines` / `CollapsibleList` / `SubjectFilterTabs`，以及全局类 `page` / `page-head` / `eyebrow` / `serif` / `card` / `meta` / `badge` / `quiet-empty` / `fade-key` / `seg` / `drawer-sec` / `verify-badge` / `xlink` / `slash-*` / `pf-toast`。替换成 ui-next 的 `Button`、`IconButton`、`Chip`、`ChipButton`、`ChipToggle`、`FoldList`、`RetryLine`、`SkeletonLines`、`SectionHead`、`ToastHost` / `showToast`，图标用 lucide。
- **列表页**：标题“笔记”下面一句状态（“共 N 篇。”，筛选或搜索时是“找到 N 篇。”，第一次加载完成前留空），再加一句说明。搜索框沿用题库页的样式；科目筛选改成 `ChipToggle` 一排（仍是 `fieldset` + “科目”，单选，用 `aria-pressed` 标出）。没有用 `Segmented`，因为自定义科目数量不定，分段控件会撑破。列表是带细分隔线的行：类型图标、标题、“类型 · 第 N 版 · 日期”、右箭头。加载 / 出错 / 为空依旧一次只显示一种，顺序和原来一样（加载 → 出错 → 空 → 行）。
- **阅读页**：保留三栏（大纲 · 正文 · 右栏信息）。顶栏吸顶（不透明，底部一条细线），从左到右是返回、大纲开关（`IconButton`，加了 `aria-pressed`）、阅读 / 编辑（两个只响应点击的按钮，用 `aria-pressed` 标出当前项）、编辑时的“保存”主按钮。大纲栏和右栏在宽屏上随页面吸顶；1180px 以下右栏移到正文下方，880px 以下大纲和大纲开关隐藏。入口提示条、入口一排（当前入口用强调色 `ChipButton`）、类型 / 校验状态 / 版本都还在。右栏四段用 `SectionHead`：属性（`dl`）、关联知识点、相关学习项（`FoldList`）、活动 · AI 修订（`FoldList` 时间线，“还原”是安静按钮，已还原的显示“已还原”标签）。
- **正文块**：28px 手柄栏 + 内容的网格不变，小节标题常显折叠按钮，其他块悬停或聚焦时显示锚点按钮；没有悬停能力的触屏上一直显示。折叠箭头的旋转从内联样式挪到 CSS，只在点击时转。`scroll-margin-top: 84px` 保留，所以深链滚动的落点不变。易错段落保留左侧警示线，例子段落保留浅底。
- **编辑器**：手柄栏（拖动、插入、删除）、键盘上下键调整顺序、所有 aria 标签都不变。插入菜单和两个选择器是这页唯一的浮层，所以只有它们用了玻璃（`un-glass`），打开时有一次短促的淡入上移，用户设置了减少动效时不播放。TipTap 编辑区重新补回了列表、代码、引用这些样式（ui-next 的基础重置会把它们清掉）。
- **提示条**：本地的 `say` 改为调用 `showToast`，提示由 ui-next 的 `ToastHost` 显示（玻璃，右下角）。文案一字未改；停留时间从 5 秒变成全站统一的 4.5 秒。
- **嵌套三元**：大纲符号原来是嵌套三元，现在改成小函数 `outlineGlyph`；列表空状态的文案改由 `emptyCopy` 决定。

## 逻辑未变的证明

方法：先从 HEAD 存一份原文件。对新旧两版分别用 TypeScript 编译器去掉 import 和注释，把每个最外层 JSX 表达式换成占位符 `JSX` 再打印出来，然后逐行比对（第一遍）。JSX 里的事件处理和 ref 也是逻辑，所以第二遍把所有 JSX 属性中的函数 / ref / `on*` 表达式提出来，排序后再比对。

第一遍（JSX 之外的代码）剩下的差异，全是呈现层面的：
- `NotesPage`：新增 `countSentence`、`emptyCopy`、`SubjectChips`（科目筛选组件）、`listBody`（把原来的四段三元换成按同样顺序的 if 链：加载 → 出错 → 空 → 行）。
- `NoteReaderPage`：新增 `ReaderFrame`、`VerifyChip`、`outlineGlyph`；常量 `NRB_PLAIN_CLASS` 改名为 `BLOCK_KIND_CLASS`，值换成新 class 名；删掉了 `toast` 状态；`say` 的函数体从 `setToast(text); setTimeout(() => setToast(null), 5000)` 改成 `showToast({ message: text })`。这是裁定允许的提示条改动，`conflictToast` 和它的两个调用点逐字不变。
- `NoteBlocks`：`KIND_ICON` 的值从图标名换成 lucide 组件；新增 `VerifiedChip` 和 `KindIcon` 局部变量。

## 2026-11-07 更新：阅读排版和笔记（YUK-1966）

Owner 2026-11-05：「版式算是过关，但并不易读，不够眼前一亮」。2026-11-07 看过同一篇内容在笔记、回复、题面的对比，原话「方案A是对的，但是渲染有问题」。

**方案 A，写进 `src/ui-next/reading.css` 和 `tokens.css`，所有阅读位置一起变：**

- 还是原来的黑体。正文颜色略浅，一二级标题最深，三四级标题用主色。行距 1.8，回复 1.78，段距和标题前留白加大。
- 重点句像荧光笔划过。公式单独一块浅底，居中。引用是浅色卡片，不用竖条。列表序号和圆点用主色。表格只留横线，表头有底色，放不下时左右滑动。

**渲染问题：**

- 表格：所有用 `MathMarkdown` 的位置都支持 Markdown 表格。以前只有学习伙伴回复开了，笔记里的表格露出 `|` 原文。单个 `~` 是普通文字，`~~` 才是删除线。
- 公式后的标点不掉到行首，「（」不留在行尾：公式 LaTeX 不超过 40 个字符时，和标点放在一行。更长的公式要能折行，所以不绑定。
- 任务项和普通项可以在同一个列表里，普通项的圆点不丢。

**笔记：**

- 大纲列出正文里的小标题，点击跳到那个标题。一篇笔记常常只有一段，按段列大纲只有一行。没有小标题的段落仍按原来的方式列。
- 鼠标设备上，块操作手柄放到页边，正文和标题左边缘对齐。触屏和窄屏手柄占位不变。
