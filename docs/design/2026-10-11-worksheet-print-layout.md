# 作答卷印刷版式与区域图契约（ADR-0074 D4 · 界面线提议）

状态：提议，owner 已选 B 版样式（2026-10-11 16:44）。版式渲染与区域图输出由界面线负责（ADR-0074 D7）；发放（issuance）、身份码内容、回收对位、读作答由功能线负责。**定位标记与二维码的尺寸、位置、填充**直接决定回收能否对位，由界面线与功能线共同签字确认。

样稿是本机评审产物（局域网 `192.168.50.76:8813`，真题，不入库）：`sample-worksheet-b.pdf`、`worksheet-b.html`。仓库里只放用同一次渲染产出的区域图样例 `docs/design/worksheet-sample/region-map-b.json`，其中 unit id、option id、短码都是占位。

## 1. 页面

- A4 竖版 210×297mm；带文章的题用 A4 横版 297×210mm，文章在左、题在右（R9）。同一份 PDF 可混排，每页各自方向。
- 全部矢量：文字、公式（KaTeX）、点阵/方格/横线、选项圈都是矢量路径，PDF 内不含位图（题图除外）。
- 页头一行：「作答卷」+ 来源 + 日期；右上角短码与二维码；页脚「做完后在 Loom 里点『传回作答卷』」+ 页码。卷面不出现答案、内部编号或计分单元 id。

## 2. 坐标、定位标记与身份码

- **唯一的规范坐标是页面毫米**（`mm`，原点为页面左上角）。区域图里所有位置（定位标记中心、二维码框、作答区、选项圈）都用它表示，不另设第二套坐标。
- 四角各一个定位方块，边长 5mm，外缘距纸边 6mm（中心距纸边 8.5mm）。TL、TR、BL 实心；**BR 空心**，描边 1.2mm。区域图逐页给出四个中心的 `mm` 坐标。
- 回收端先用空心的 BR 定方向（旋转 90°/180°/270°、翻面），再用**四个**定位中心到其 `mm` 位置拟合一个透视（投影）变换，把照片或 GoodNotes 导出页还原到页面毫米，再按区域切图。不能只用两个角：照片有旋转、透视和纸面不平。二维码自己的三个定位图案可作方向的第二重校验。
- 二维码 13mm，位于右上角，区域图给出它的 `mm` 框，便于先裁切再识别；内容提议为 `tlp://ws/<短码>/<页>/<总页>`，人可读短码同排印出（如 `TLP-7K2Q · 第 2/4 页`）。短码到 issuance id 的映射与二维码最终格式由功能线定。拍照识别率不足时放大到 16mm。

## 3. 区域图结构

顶层：`schemaVersion`、`shortCode`、`webOnlyUnits[]`、`pages[]`。每页：`page`、`of`、`orientation`、`sizeMm`、`qr { payload, mm }`、`anchors { tl, tr, bl, br }`、`regions[]`。

| kind | 含义 | 携带 |
|---|---|---|
| `writing` | 一个计分单元的预留作答区（解答/填空/过程/需要画图的题） | `unit`、`seq`、`mark`（`dots` 点阵 / `squares` 5mm 方格 / `ruled` 横线）、`mm` |
| `choice` | 一个计分单元的选项圈（单选/不定项、完形每空） | `unit`、`seq`、`options[]`：每个圈的 `optionId`（**稳定选项 id**，ADR-0073）、`label`（印出的字母，只给人看）、`mm` |
| `draft` | 草稿区，**不判分**，回收时忽略 | `mark`、`mm` |

- **选项一律按 `optionId` 回收**。选项顺序随 issuance 冻结（ADR-0073 option_order），印出的字母和稳定 id 可能不同，回收不能用字母。
- 一个计分单元跨页续写时，各页各有一个同 `unit` 的区域，`seq` 从 1 递增，按 `seq` 拼接。
- **每个计分单元都必须有着落**：要么在某页有至少一个 `writing`/`choice` 区域，要么列在 `webOnlyUnits[]`（说明在网页作答，如断句的字间点选、配对题的点选）。回收端据此区分「不在纸上」和「留空」，二者不能混同（ADR-0073）。
- 标号（owner 16:44）：大题＝实心珊瑚色圆角方块；小问、完形的空、作答区标签＝珊瑚色细圆环，同一号码在题干、作答区、文章空位处一致。标号只给人看，回收不依赖它。

## 4. 导出与回收的分工

- **导出（功能线）**：生成 issuance，冻结选项顺序（ADR-0073 option_order），把真实计分单元 id 与选项 id 填进渲染输入；渲染器（界面线）按本版式出 PDF，并**同时产出区域图**（与 PDF 同一次渲染、同一份 DOM 量出的坐标），由功能线随 issuance 存档。
- **回收（功能线）**：裁出并读二维码→找 issuance 与页→用 BR 定方向→四角拟合透视变换还原到页面毫米→按 `mm` 切出每个区域→`choice` 按 `optionId` 判圈涂、`writing` 交 capture 读作答→进同一判分；`webOnlyUnits` 不从纸上读。找不到身份码或定位标记时，退回普通照片录入并如实标注（ADR-0074 D4）。

## 5. 未决（随第一刀实测定）

- GoodNotes 导出时横版页是否保持横向、是否加边距——不影响对位（透视变换由四角决定），但影响版面观感，owner 首轮实测后定。
- 二维码 13mm 与定位标记 5mm 在手机照片下的识别率；不足则二维码放大到 16mm、定位标记放大到 6mm。
- 断句：ADR-0074 D4 回收清单里列了「断句斜线」，但 D1/D3a 已定断句在网页字间点选。本提议按 D3a 把断句放进 `webOnlyUnits`，不印作答区；若要保留纸上断句，需在 ADR-0074 里改一处说法。
