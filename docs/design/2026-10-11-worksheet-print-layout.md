# 作答卷印刷版式与区域图契约（ADR-0074 D4 · 界面线提议）

状态：提议，owner 已选 B 版样式（2026-10-11 16:44）。版式由界面线负责（ADR-0074 D7）；发放（issuance）、身份码内容、回收对位、读作答由功能线负责。本文件只定**版面上画什么、画在哪里、怎么告诉回收端**。

样稿（局域网，真题，不含密钥）：`http://192.168.50.76:8813/sample-worksheet-b.pdf`，区域图 `region-map-b.json`，源 `worksheet-b.html`。

## 1. 页面

- A4 竖版 210×297mm；带文章的题用 A4 横版 297×210mm，文章在左、题在右（R9）。同一份 PDF 可混排，每页各自方向。
- 全部矢量：文字、公式（KaTeX）、点阵/方格/横线、选项圈都是矢量路径，PDF 内不含位图（题图除外）。
- 页头一行：「作答卷」+ 来源 + 日期；右上角短码与二维码；页脚「做完后在 Loom 里点『传回作答卷』」+ 页码。卷面不出现答案、内部编号或计分单元 id。

## 2. 定位标记与身份码

- 四角各一个定位方块，边长 4mm，中心距纸边 8mm。TL、TR、BL 实心，**BR 空心**，用于判断旋转/翻面。
- 二维码 13mm，右上角，内容提议为 `tlp://ws/<短码>/<页>/<总页>`；人可读短码同排印出（如 `TLP-7K2Q · 第 2/4 页`）。短码到 issuance id 的映射与二维码最终格式由功能线定。
- 区域坐标以 **TL 与 BR 定位标记中心张成的框**为参照：`frame` 坐标 u、v 取 0–1（TL 中心为 0,0，BR 中心为 1,1）。GoodNotes 导出或拍照后只要找到四角，就能按比例还原，不依赖页边距或缩放。

## 3. 区域种类（区域图 `regions[]`）

| kind | 含义 | 携带 |
|---|---|---|
| `writing` | 一个计分单元的预留作答区（解答/填空/过程） | `unit`、`mark`（`dots` 点阵 / `squares` 5mm 方格 / `ruled` 横线）、`mm`、`frame` |
| `choice` | 一个计分单元的选项圈（单选/不定项、完形每空） | `unit`、`options[]`：每个圈的 `option`（选项稳定 id）、`mm`、`frame` |
| `draft` | 草稿区，**不判分**，回收时可忽略 | `mark`、`mm`、`frame` |

- 一个计分单元可以跨页续写时，各页各有一个同 `unit` 的 `writing` 区域，按页序拼接。
- 标号（owner 16:44）：大题＝实心珊瑚色圆角方块；小问、完形的空、作答区标签＝珊瑚色细圆环，同一号码在题干、作答区、文章空位处一致。标号只给人看，回收不依赖它。

## 4. 导出与回收的分工

- **导出（功能线）**：生成 issuance，冻结选项顺序（ADR-0073 option_order），把真实计分单元 id 与选项 id 填进渲染输入；渲染器（界面线）按本版式出 PDF，并**同时产出区域图**（与 PDF 同一次渲染、同一份 DOM 量出的坐标），由功能线随 issuance 存档。
- **回收（功能线）**：读二维码→找 issuance 与页→找四角→按 `frame` 坐标切出每个区域→`choice` 判圈涂、`writing` 交 capture 读作答→进同一判分。找不到身份码或定位标记时，退回普通照片录入并如实标注（ADR-0074 D4）。
