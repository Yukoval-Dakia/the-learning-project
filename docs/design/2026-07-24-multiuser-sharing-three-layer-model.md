- **性质**：D1′（隔离宇宙租户模型）的姊妹篇——本文回答「隔离之后，共享还剩什么、怎么共享」。

## 0 · 两条 owner 判断（本文公理）

1. **「我们几乎没有可以共享的东西，包括 KC 在内。因为每个人要学的东西不一样。」**——个人状态与个人知识图谱不可共享；多用户的基座是 N 个隔离宇宙，不是共享语料库 SaaS。
2. **「但我隐约觉得可以想出一套好的方法让多用户数据有共享的作用。」**——本文即对这条直觉的成形化。

两条并不矛盾：**状态不可共享 ≠ 从状态蒸馏出的统计事实不可共享**。方案的全部要点是把这两者分开。

## 1 · 三层模型

### 第一层 · 内容层（弱共享：copy-on-import）

教材、题目、KC 骨架、subject bundle。个人组合各不相同，但原子内容在同考纲/同教材人群中大量重叠。

- **共享形态**：导入即复制（copy-on-import）。每个宇宙持有自己的行，溯源字段记来源；绝不共享可变行。等价于 git fork 而非共享分支。
- **身份机制**：内容寻址。`canonical_content_hash`（已存在于 question 表）即跨宇宙的内容身份——两个宇宙各自持有的同一道题，无需任何协调即可被识别为「同一道」。
- **存储去重**：R2 层内容寻址（未来项，非必需）。
- **现有雏形**：`subjects/<name>/` bundle 就是随代码发行的共享骨架——共享的是「地图模板」，每个宇宙在其上生长私有的「疆域状态」。KC 骨架共享可循此模式：社区/官方骨架包 → 导入 → 个人裁剪生长。

### 第二层 · 校准层（强共享：联邦统计——真正的金矿）

个人状态私有，但 N 个宇宙对**同一内容身份**产生的匿名统计事实，天然可池化且人越多越值钱：

| 共享物 | n=1 的困境 | N 用户后 | 现有挂点 |
|---|---|---|---|
| **题目难度/区分度**（IRT/Elo 参数） | 每道题的 θ 证据来自一个人，数据饥饿 | 按 content_hash 池化作答结果 → 真实 item 校准 | A1/A2 θ 机制、`canonical_content_hash` |
| **FSRS 权重先验** | 只能用全局默认权重 | 匿名复习日志池 → 人群先验 → 个人微调 | ts-fsrs（其默认权重本就来自社区共享日志——本产品已在吃这个模式的红利） |
| **misconception 分类学** | 个体错误样本稀薄 | 错误**模式**跨人泛化 → 共享误解库 → 每人诊断更准 | parked 的 misconception 建模 + MISCONCEPTION_PROMOTE 设计 |
| **验题成本摊销** | 五轴 verify 每宇宙自费 | verified 状态随内容哈希共享，一人验过全网受益 | B5 统一 verify 契约（YUK-350） |
| **judge 校准** | 误判模式靠单人申诉积累 | 申诉/重判结果池化 → 判分路线级校准 | YUK-589 provenance digests、rejudge 链 |
| **教学法功效**（谨慎） | 功效学习无数据 | method × KC-type 功效信号池化 | YUK-506 pedagogy palette（deferred 的 efficacy learning）；**必须**继续遵守 anti-learning-styles 三锁——共享的是「方法×内容」功效，绝不是「学习风格×人」画像 |

**机制**：
- **贡献通道** = 事件订阅。宇宙内一个 subscription（刚通电的事件总线正是这个形状）把选定事实匿名化、内容寻址后发布到聚合面：`(content_hash, outcome, latency_band, …)`——无用户身份、无原文、无自由文本。
- **消费通道** = copy-on-import 的特例：定期拉取版本化的先验包（难度参数表、FSRS 权重、误解分类、verified 清单），作为**先验**注入个人估计器——个人数据始终覆盖先验（Bayesian 更新方向：pooled prior + personal likelihood）。
- **信任边界**：聚合面只见哈希与统计量。这是联邦学习的形状：**共享统计，不共享数据**。

### 第三层 · 状态层（永不共享）

θ̂、FSRS 状态、attempt/review 历史、个人 KC 图、笔记、档案、事件流。隔离宇宙的定义域。备份契约（49 表 FK_ORDER）就是这一层的**可移植格式**——宇宙快照。

## 2 · 与隔离宇宙架构的关系：零冲突

- 共享不引入任何共享可变行 → 不动租户模型（D1′：不加 user_id 列；实例/schema 隔离）。
- 贡献/消费都是宇宙**边界上的显式通道**（事件订阅 + 导入），不是宇宙**内部的**跨租户查询。
- 今天已建成的四样地基原语恰好齐备：`canonical_content_hash`（内容身份）、`sha256Canonical`（规范化哈希，YUK-589）、事件总线（贡献通道，YUK-751）、备份契约（宇宙格式）。方案是既有架构的自然延伸，不是新造引擎。

## 3 · 分期形状（仅形状，不排期）

- **P0（已在发生）**：单用户期一切照旧。守住内容寻址纪律（新内容型表都带 canonical hash）——这是唯一的「现在要做」，成本≈0。
- **P1（第二个用户出现时）**：verified 摊销 + 难度先验（最小聚合面：一张按 content_hash 的统计表 + 拉取端点）。
- **P2（第 N 个用户）**：FSRS 先验、misconception 库。
- **P3（远期）**：教学法功效池、内容市场（骨架包/题包发布）。

## 4 · 待研究问题（owner「再研究研究」的清单）

1. **等价性判定**：content_hash 是字节级同一。语义等价（同题不同措辞、数值变式）要不要进校准池？变式家族（item-model）天然给出「模板级」池化键——可能比字节哈希更对。
2. **匿名化强度**：单聚合面运营者（=owner）模型下，匿名化是防将来第三方还是防运营者自己？决定聚合粒度（原子事实 vs 预聚合分桶）。
3. **冷启动悖论**：先验包对新宇宙价值最大，但新宇宙贡献最少——免费拉取 or 贡献换取？（家庭/小班场景下大概率无所谓，市场化才是问题。）
4. **污染防御**：恶意/低质宇宙污染校准池（乱答题拉偏难度）。加权（按宇宙内一致性）、离群截断、或仅信任圈内池化。
5. **KC 骨架的「好的方案」**：owner 原话中的悬案。候选：官方考纲骨架包（人教版文言文 KC 树）+ 个人 overlay；或纯 emergent（各宇宙自长，仅在校准层经内容哈希间接对齐）。倾向后者起步、前者作为导入包补充——待研究。
6. **法务/伦理**：未成年人学习数据的统计池化，即便匿名，市场化前需过一遍合规（家庭/自用场景不触发）。

## 5 · 对 D 菜单的影响

- **D1 → D1′**：不加 user_id 列；租户=宇宙（实例/schema 隔离）。本文不改变该结论，反而强化——共享走边界通道，行级租户的理由进一步消失。
- **D2**：锁名租户维度**不需要**（锁永远在宇宙内）。降级为「无动作」。
- **新增守则候选（随 P0）**：新内容型表必须带 canonical content hash（写进耦合守则的姊妹条款）——这是未来一切共享的身份地基，事后补装最贵。
