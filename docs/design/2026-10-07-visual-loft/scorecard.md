# YUK-1353 loft 评分表

评分人：Claude Opus 5.5（作者），依据真实 Chromium 截图、录屏与指标；独立复核见 [review.md](review.md)。
评分对象：A 第二版（loft 内修订后）、B、C。A 第一版截图在 `evidence/round-1/`。

刻度：5 = 桌面与手机都满足；4 = 满足但有一处已记录的弱点；3 = 只在一种设备上满足；2 = 部分满足；1 = 不满足。
“复用成本”一项分数越高表示成本越低。

## 4. 实测指标

Headless Chromium 151.0.7922.34（Apple silicon），本地 fixture，每格 3 次运行取中位数（最大值另列）；`cpuThrottle 4` 为低端机代理。
脚本：`prototype/capture.mjs metrics`；原始数据：`evidence/metrics.json`（含每次运行与每个交互窗口的帧间隔）。
INP 代理值 = 本次操作序列中各交互（按 interactionId 合并）事件时长的最大值；帧间隔 = 交互后 600ms 内相邻 rAF 的最大间隔。

| 变体 | 设备 | CPU | CLS（最大） | INP 代理 中位 / 最大 | 空闲基线帧间隔 | 切屏帧间隔 | 插入步骤帧间隔 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A | 桌面 | 1× | 0.0007 | 64 / 64 ms | 26 ms | 52 ms | 27 ms |
| A | 手机 | 1× | 0.0133 | 56 / 56 ms | 27 ms | 39 ms | 27 ms |
| B | 桌面 | 1× | 0.0133 | 48 / 56 ms | 27 ms | 35 ms | 27 ms |
| B | 手机 | 1× | 0.0134 | 48 / 48 ms | 27 ms | 30 ms | 37 ms |
| C | 桌面 | 1× | 0.0038 | 48 / 48 ms | 27 ms | 27 ms | 27 ms |
| C | 手机 | 1× | 0.0066 | 48 / 56 ms | 27 ms | 45 ms | 28 ms |
| A | 桌面 | 4× | 0.0007 | 88 / 96 ms | 27 ms | 104 ms | 114 ms |
| A | 手机 | 4× | 0.0126 | 72 / 72 ms | 27 ms | 101 ms | 100 ms |
| B | 桌面 | 4× | 0.0133 | 104 / 104 ms | 27 ms | 109 ms | 104 ms |
| B | 手机 | 4× | 0.0127 | 72 / 80 ms | 27 ms | 109 ms | 96 ms |
| C | 桌面 | 4× | 0.0038 | 80 / 80 ms | 27 ms | 78 ms | 94 ms |
| C | 手机 | 4× | 0.0066 | 72 / 72 ms | 27 ms | 92 ms | 94 ms |

判读：

- **CLS < 0.05**：全部通过（最大 0.0134）。
- **INP < 200ms**：全部通过（4× 降速下最大 104ms）。“100ms 内反馈”在 1× 全部满足；4× 下 B 桌面中位 104ms 略超，其余 ≤ 96ms。
- **关键交互 60fps**：**未达成**。空闲时 headless 帧调度本身就有约 27ms 的间隔（基线），1× 下各交互与基线同级；但 4× 降速下
  切屏与插入步骤在三个变体中都出现 78–114ms 的长帧。原因是整页 View Transition 快照加整屏渲染；对策写入决策 M3（页内改用元素级 FLIP）
  与 M6（公式等昂贵渲染前移到服务端或空闲预取），并须在真实中端手机复测。
- **公式预热的作用**：第一次测量（未预热、单次运行，`evidence/metrics-before-math-warmup.json`）4× 下 INP 为 A桌面 88ms、A手机 168ms、B桌面 112ms、B手机 200ms、C桌面 240ms、C手机 112ms；
  空闲预热公式后中位数降至 72–104ms。单次运行波动大，因此结论只取 3 次中位数。
- 指标只说明布局与交互本身的成本；生产的数据加载、网络与服务端渲染须在 YUK-1354 起按真实路由测量。
- 三个变体的差异小于运行间波动，**性能不构成选择理由**；选择依据为 §1。

## 5. 结论

选定 A 第二版；理由与不选 B/C 的理由见[决策文档 §1](../2026-10-07-ui-visual-direction.md#1-选定方向a纸页第二版)。
B 的同屏原则与手机标签栏、C 的“停下同级可选”与“关联写依据”已作为规则吸收（W2、N2、H2、H8）。
