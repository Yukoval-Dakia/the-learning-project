## 做了什么

- **呈现重写**：旧的 `LoomCard` / `LoomIcon` / `BrandMark` 与全局 `page` / `chip` / `composer` / `serif` 类，换成 ui-next 的 `ChipToggle`、`Segmented`、`Button`、`Mascot` 与 lucide 图标。两组问题各放在一块 M3 surface-container-low 面板里；「怎么开始」是两张可点的卡片，上传材料那张用 secondary-container 作主选项。标题与今日页、练习列表一致。
- **步骤条**：新组件 `OnboardingSteps`（有序列表，当前步骤 `aria-current="step"`，已完成步骤带读屏文字）。旧 `ObSteps` 还有备料、定位、档案三页在用，最后一页迁完时删除。
- **禁用的学科 chip**：ui-next 的 `ChipToggle` 原来没有禁用态，本页是第一个用到禁用 chip 的页面。补上禁用态：变暗（0.45，与 `un-chip-action` 一致），不再有悬停反馈。这样未配置的学科看得出点不了，和旁边的说明文字对得上。
- **可访问性**：每组选项用 `fieldset` + `legend`；目标为空或保存失败时用 `role="alert"` 提示，并通过 `aria-describedby` 关联到输入框。
- **共享 M3E 改指**：题库、录入、本页的 `main` 都挂 `.un-m3e-bridge`（`components.css`），把旧 `--un-*` 颜色别名改指到 M3 角色。三处原来各写一份，现在只有一份。
- **删除旧样式**：`onboarding.css` 里只属于本页的 44 条规则删除（按「前面不是字母或连字符」匹配类名，确认没有其它 TSX 再用）。本来就没人用的旧类（`ob-opt*`、`ob-pl-*`、`ob-settle-s`）不属于本片，不动。
