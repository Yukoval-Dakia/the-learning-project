> - **M1 只在变化时动**：没有用户动作或数据变化时，页面上没有任何东西在动（包括吉祥物与背景）。
> - **M2 每个动画回答一个问题**：这个东西从哪来、到哪去、算不算数。回答不了的动画不做。
> - **M3 可以打断**：任何过渡进行中都可以被新的操作接管，不先跳到终点，也不留下残影、隐藏的元素或卡在中间的状态。按实现方式分两类：

>   - **CSS 过渡**（面板宽度、展开、计数）：从当前位置转向新目标（CSS 不保留速度）。
>   - **一次性飞行**（形变、收进去、引用飞入）：取消当前飞行，并**从正在飞的副本此刻的位置**重新起飞；被撤销的飞行在原地淡出，不再到达。
>   - `prefers-reduced-motion` 下所有过渡直接切换（含字面量时长），程序滚动改为瞬时，吉祥物不转动，状态只靠文字表达。

> ## 9A. 可达性（A）
> 
> - **A1 收起即不可达**：收起的学习伙伴、折叠的“为什么 · 换一种”、关闭的命令面板与记录表单、让位隐藏的标签栏、露出状态下抽屉的正文，

>   玻璃上的次级文字按最不利背景计算。复核实测的不达标组合：亮色 `--positive` / `--positive-soft` 4.30:1，`--accent-strong` / `--bg-hover` 4.42:1，
>   玻璃上 `--text-3` 最坏约 3.05:1（亮）/ 2.28:1（暗）。生产落地 token 时须修正，并让禁用状态有可见区别（原型已加）。
> - **A4 键盘路径**：新的交互都要有键盘入口：引用与页边标记是按钮（原型已满足）；对选中文字提问、抽屉的各停靠点在原型里只有指针路径，生产须补上。

## 2. 组件类型

**other（设计系统库）**：一组可复用的 token、基础组件、外壳与动效工具，加一个展示组件。不是 route，不挂入任何路由；
展示页只交付组件与 props，路由由 Start 的 owner 另行挂载（I4）。

库内包含以下形态，供后续 UI 波次使用：

- shell：主框（可折叠侧栏槽 + 顶栏 + 学习伙伴侧栏位），属 N2、C1 的机制；
- drawer：手机底部抽屉（C2）；
- modal：命令面板（N4），复用现有 `useFocusTrap`；
- 浮层：提示条（M10、M15）；
- 手机标签栏（N3 的机制；条目由调用方传入，条目本身属待定层）。

**不包含**（各有归属）：吉祥物（YUK-1395，新增 three.js 依赖须另行协调）；学习伙伴的消息与输入框（C3、C4、C6 的界面随学习伙伴那一波）；
任何待定层的页面组成（H、R2、L1–L3、C5 等）。

## 5. 关键实现决定

- **作用域**：所有样式挂在 `[data-ui-next]` 之下，不使用 `@layer`。`web/src/globals.css` 的元素规则都没有分层，放进 layer 会被它们压过；
  作用域选择器的特异性高于全局元素选择器，并在作用域内显式重置 `button`、`p`、`h*`、`a`、`ul/ol`、`:focus-visible`。
- **主题**：沿用现有机制：`<html data-theme>`（`loom-theme`）为显式选择，缺省时跟随 `prefers-color-scheme`（T6）。展示组件可在自身根上局部覆盖，便于并排检查亮暗。
- **对比度**：修正复核记录的三组不达标组合（A3）：状态色与其 soft 底、强调色与 hover 底、玻璃上的次级文字。由单元测试从 `tokens.css` 读取取值并计算对比度，亮暗两套都检查。
- **字体**：不引入任何外部 URL（CSP 只允许同源字体）。本票只声明本地字体栈；自托管需要许可证文件与 woff2 转换，单独开票 [YUK-1399](https://linear.app/yukoval-studios/issue/YUK-1399)。
- **对 T3 的修订**：玻璃底色从原型的 64% 提高到 86%，否则次级文字在最不利背景上只有 3.05:1 / 2.28:1（A3）。T3 属稳定层，已回写决策文档（PR #1612 `b50330dbc`）。
- **快捷键**：⌘K 由现有 `RootShell` 全局绑定，基座不做全局绑定；组件只暴露受控的打开状态与回调（N5 的绑定由页面或外壳的使用方决定）。
- **焦点与弹层**：命令面板与抽屉复用 `src/ui/primitives/useFocusTrap`，与现有弹层共用同一个 Esc 堆栈；收起的区域用 `inert`（A1）。
- **Tailwind 扫描**：`web/src/globals.css` 的 `@source "../../src"` 会扫描本目录。类名一律 `un-` 前缀，并用构建产物对比确认 `web/dist` 与 `dist/start` 不因本目录而变化。

## 6. 验收方式

- 单元测试：键盘路径（分段、抽屉停靠点、命令面板、提示条撤销）、`inert`、减少动态效果、token 对比度。
- 浏览器截图：在一个只用于验收的本地 harness 中渲染展示组件（桌面 1440×900 / 手机 390×844 × 亮 / 暗），harness 不入库。
- 生产产物：本 PR 前后 `web/dist` 与 `dist/start` 的产物对比。
- 本机：`pnpm typecheck`、`pnpm lint`（含 lint ratchet）、`pnpm build`，以及匹配的 scoped unit 测试；不运行完整 `pnpm test`。
- 独立视觉复核：另起 Claude Opus 5.5。
