## 1. 选定方向

一句话：**像 Linear 一样克制的工作软件外壳，内容旁边常驻学习伙伴；玻璃只给浮层，动效只在变化时出现、可以打断，并说清东西从哪来、到哪去、算不算数。**

| 方面 | 选定 |
| --- | --- |
| 外壳 | 左侧可折叠侧栏（248 ↔ 60px）+ 内嵌圆角主框；主框里是 48px 顶栏和内容。`⌘K` 命令面板，`⌘\` 折叠侧栏 |
| 页面 | 回来时（含快速记录）、题目、笔记、资料四类。题目与笔记是阅读与复盘页，不是手写解题页 |
| 学习伙伴 | 内容旁边常驻侧栏（384px），`⌘J` 开合；默认在题目、笔记页打开，在回来时、资料页收起。手机上是可拖动的底部抽屉 |
| 手机 | 底部悬浮玻璃标签栏：回来时 / 资料 / 记一下 / 学习伙伴。往下读时标签栏收窄，往回滚时恢复 |
| 视觉 | 暖纸暖墨、唯一的珊瑚强调色、衬线叙述标题。层级靠字号、字重、灰度与底色差；玻璃只给浮层 |
| 品牌 | 吉祥物是一朵透明玻璃风车花，三维，每页 banner 一朵。logo 是另外设计的二维编织方块 |

原型：`docs/design/2026-10-07-visual-loft/prototype/`，入口 `index.html`。运行方式见 [README](2026-10-07-visual-loft/README.md)。

### 1.1 为什么这样选

1. **贴近真实使用。** owner 明确了主要场景：回顾、看题目、读笔记、与学习伙伴协作；手写暂不在内部做。
   因此主体是阅读页，帮助集中在常驻的学习伙伴里，不再为手写草稿设计三栏工作台。
2. **学习伙伴是常驻搭档，不是弹窗。** 它固定在内容旁边，并知道“正在看”的是什么。
   回答里的引用可以点回正文，正文里被引用的段落也能点回对话（R5、C4）。
3. **高级感来自克制与准确。** 结构参照 Linear 的密度与侧栏，质感参照 Apple Liquid Glass，但玻璃只用在浮层上。
   卡片不投影，正文区没有装饰性动画。
4. **顺畅感来自连续。** 每个动画都回答一个问题：这个东西从哪来、到哪去、算不算数。动画只在变化时出现，任何时候都可以打断（M 节）。

### 1.2 演进过程

| 轮次 | 内容 | 结果 |
| --- | --- | --- |
| 第一轮 | A 纸页、B 工作室、C 学习线三个结构变体，首页 + 手写解题工作台 | 两轮独立复核后选 A + 三区同屏工作台（commit `147ce1615`）。owner 之后要求重新探索 |
| 探索 | D/E/F：贯穿的几何动画、毛玻璃与液态元素 | owner 否决：“表现欲太浓，不优雅美观，也没有考虑产品实际” |
| 讨论 | 动效只在变化时出现；参考 Linear 与 Apple Glass；三维几何或花作为随动标志物；结构与质感一起重来；聚焦回顾、阅读与协作；首页要有快速记录 | 先做标志物三样稿（花 / 几何 / 结），再整体 |
| 第二轮 | 吉祥物定为玻璃风车花（建模由 owner 指定的 Astra agent 完成），logo 单独设计；一套贴近产品的完整方案；手机布局；四组连续动画 | owner 认可，选定 |

第一轮的原型与证据只保留在 git 历史里（commit `147ce1615` 的 `docs/design/2026-10-07-visual-loft/`），
它们的规则已按本文重写，**不再作为引用来源**。

## 2. 导航骨架（N）

- **N1 侧栏**
  - 自上而下：品牌（logo + 字标）与折叠按钮；“搜索或跳转 `⌘K`”；主去处“回来时 / 资料”及资料下的“题目 / 笔记 / 错题”（带计数）；
    “我的学习”；“收进来的”（带计数）；“系统为我做了什么”（带计数）；“最近和学习伙伴”的对话；底部是外观切换。
  - 折叠到 60px 时只留图标，文字与计数淡出；宽度变化是布局过渡（见 M8）。
- **N2 主框与顶栏**
  - 主框内嵌，四周留出侧栏底色，带圆角与发丝线。顶栏 48px：面包屑（资料 › 题目 › 当前项）、当前页的主动作、学习伙伴开关（`⌘J`）。
  - 页面级的主动作放在顶栏，不放在浮层里。
- **N3 手机**
  - 侧栏隐藏。顶栏左侧是返回（详情页）与页标题，右侧是吉祥物的停靠位（B3）。
  - 底部悬浮玻璃标签栏：回来时 / 资料 / 记一下 / 学习伙伴。“记一下”是唯一的实心按钮，带“收进来的”计数。
  - 往下读超过 80px 时标签栏收窄；学习伙伴抽屉拉到一半或全屏时，标签栏让位隐藏。
- **N4 命令面板**：`⌘K` 打开，玻璃浮层。分组为“前往 / 继续 / 动作 / 外观”，高频动作显示快捷键，方向键选择，回车执行，`Esc` 关闭。
- **N5 快捷键**：`⌘K` 面板、`⌘J` 学习伙伴、`⌘\` 侧栏、首页 `N` 聚焦快速记录。按钮内显示快捷键，触屏隐藏；只有图标的按钮必须有可访问名称。
- **N6 现有导航的默认归宿**（P6 各波次票确认后实施）：
  - 今日 → 回来时；录入、收件箱 → 记一下与“收进来的”；
  - 题库、笔记、错题本、知识 → 资料；
  - 草稿审核、AI 观察、后台结果 → 系统为我做了什么；
  - Coach、画像 → 我的学习；
  - CopilotDock 浮层 → 常驻的学习伙伴侧栏（C1）；
  - 管理面（`admin-*`）不进主导航，经 `⌘K` 与设置进入。

## 3. 回来时（H）

- **H1 顺序**：
  1. banner：日期、时段与今晚可用时间；衬线一句回来时叙述，加一两句说明（包含未知与已准备好的东西）；右侧是本页的吉祥物；
  2. 快速记录（H2）与刚收进来的条目；
  3. “接着来”：等大并列的“继续你的 / 建议”；
  4. “今天”：今天可做的事，逐行说明；
  5. “系统准备的”：后台结果与状态。
- **H2 快速记录**
  - 一行输入，加拍照、口述与意图选择：“只保存 / 帮我理解 / 一起做”。回车记下。
  - 记下后立即出现在下方，并带撤销；同时飞进“收进来的”（M5）。
  - 手机上由标签栏“记一下”打开玻璃底部表单。
- **H3 并列与主次**：继续与建议同尺寸、同层级。继续在阅读顺序前位，可用回车进入。建议用“为什么 · 换一种”展开。
- **H4 建议必须说明**
  - 卡面直接给出“为了什么”与预计投入，并标注“估计”。
  - 展开后逐项给出 §7.2 要求的内容：为什么现在、需要什么、何时可以停下，以及可替代的做法。展开用 0fr → 1fr 的高度过渡。
  - 推迟是乐观写入加撤销（M10）。
- **H5 准备状态诚实**：只有可用结果才显示“准备好了”；生成中显示进度并注明“还不能开始”；需要复核用 caution 色说明原因。
- **H6 确定性能力同级**：到期复习等不依赖模型的项与 AI 建议同列，并标注“按复习间隔，不需要 AI”。
- **H7 久别与三态**：沿用行为设计的要求——久别时直说多少天没见、不累加到期任务；载入、空、出错按区域设计，
  AI 建议取不到时，继续项与确定性项照常可用。第二轮原型没有覆盖这几种状态，由 W1 波次的 UI 票补齐并截图验收。

## 4. 阅读与复盘页：题目、笔记（R）

- **R1 三位置不变量**：正在看的内容（题干、图形、笔记正文）、自己的东西（草稿步骤、作答记录、批注）、围绕它的帮助（学习伙伴）
  同时存在于屏幕上。**帮助不得覆盖自己的尝试**；打开或收起学习伙伴不改变正文内容与阅读位置（M7）。
- **R2 题目页结构**：banner（来源、标题、状态芯片：目标、范围、各小问的核对结果）→ 题目（题干、图形、小问、作业要求）→
  草稿（逐步列出，每步注明来源：作业照片 / 今晚 / 看提示后；识别不清的部分注明“未用于判断”）→ 我的作答（时间线）→
  系统目前的理解。
- **R3 判分与解释分开**：确定性核对的结果明确陈述（“与参考答案不一致（确定性核对）”）；原因还没判断时直接写明，不按最终答案解释能力（§6.3）。
- **R4 不确定的呈现**：理解按“观察到 / 你说过 / 还不知道”分行，“还不知道”用中性标记，**禁止使用 critical 红色**（§6.4）；旁边有“纠正”入口。
- **R5 可引用的锚点**：草稿的每一步、笔记的每一节都是锚点（`第 N 步`、小节标题）。
  - 被学习伙伴引用过的锚点，在页边显示一个小对话标记，点它打开学习伙伴并定位到那条消息（M6）。
  - 当前正在做的一步用左侧强调线标出。
- **R6 笔记页**：衬线标题与来源说明；正文 680px 版心，按节排列；自己的批注用强调线与小字标出。
  选中一段文字时浮出玻璃气泡“问学习伙伴”，选中内容作为引用发出（M6）。
- **R7 公式**
  - KaTeX 样式表与渲染同包、按需加载。现役页面从未加载该样式表（[YUK-1379](https://linear.app/yukoval-studios/issue/YUK-1379)）。
  - 行内公式不断行；推导步骤可以在关系符处换行，并给公式行留出块向间距（KaTeX 0.19 的 strut 需要上下 0.2em 外边距）。
  - 引用、复制带公式的文字时保留 TeX 源（选区跨到公式时整段带上公式），引用里再渲染成公式。
- **R8 推广到其他活动**：阅读材料、写作反馈、听说练习沿用 R1：内容是主栏，自己的东西紧随其后，帮助在学习伙伴里并锚定到内容位置。
  具体形态在各活动的 UI 票 pre-flight 中声明。

## 5. 学习伙伴（C）

- **C1 常驻侧栏**
  - 桌面在内容右侧，宽 384px，与正文同在主框内，不覆盖正文。每个页面记住自己的开合状态；默认在题目、笔记页打开。
  - 头部：名字、状态（“在这里 / 在想…”）、收起按钮。其下是“正在看：……”，说明它看到的上下文。
- **C2 手机抽屉**
  - 可拖动的底部抽屉，三个停靠点：露出标题（peek）、一半、全屏；回来时、资料页可以完全关闭。
  - 抽屉位置是带速度的阻尼弹簧：甩动时速度带进停靠点，动画中途可以再次抓住。点按把手在露出与一半之间切换。
  - 露出时正文区淡出，只留标题行，避免内容透过标签栏。
- **C3 临时输出不冒充生效**（ADR-0066 第 45–46 行）
  - 一条回答从第一个字到记录完成是**同一个元素**，原地变化：
    1. 在想：只有状态标记；
    2. 生成中：浅灰文字加光标，标注“生成中 · 还未生效”；
    3. 记录中：文字下方有一条细线在走，标注“生成完毕 · 正在记录”；
    4. 已记录：重新读取已提交状态之后，文字过渡为正常墨色，出现“✓ 已记录”，约两秒后收起。
  - 生产中，第 4 步必须以重新读取的已提交状态为准，不能以流结束为准。
  - 吉祥物在想时转动，记录完成时前进一格花瓣（B2）。
- **C4 引用双向**
  - 回答里的“↳ 第 5 步”是按钮：正文滚到该步并亮一下。手机上抽屉先降到露出，再滚动。
  - 自己发出的引用也是按钮，点它回到原文。
  - 正文里被引用的锚点有页边标记，点它回到对话（R5）。
- **C5 需要确认的建议**：会改变学习安排的提议以卡片出现，标“建议 · 需要你确认”，有“加入 / 不用”。
  加入后卡片变为已加入的状态，并给撤销（M10）。
- **C6 输入**：两行输入框，回车发送、Shift+回车换行；在想时禁用发送并说明“它在想，稍等…”；`@` 引用正在看的内容（原型只有按钮，未实现选择）。

## 6. 资料（L）

- **L1 结构**：banner（总数与错题数）→ 分段切换“题目 / 笔记 / 错题”（带计数，滑动的墨块）→ 筛选（有待跟进、来源）→ 表头 → 行。
- **L2 行**：名称（图标、标题、副标题、待跟进点）、来源、状态、最近、下次复习。数字用 `tabular-nums`。手机上只保留名称与状态。
- **L3 进入与返回**：点行进入详情时标题形变为详情页标题；返回时落回同一行。资料页记住上次的分段（M4）。
- **L4 长列表**：真实数据量下虚拟化，由资料与题库波次的票验收。

## 7. 吉祥物与 logo（B）

- **B1 一页一朵**：吉祥物只出现在页面 banner 的指定位置。大小按页面设计：回来时 208px、题目与笔记 128px、资料 96px；手机为 112 / 84 / 68px。
  换页时同一朵花用弹簧移动、缩放到新位置，不重新创建。
- **B2 状态只跟随变化**
  - 静止时朝向读者，按页面有轻微不同的角度；任何状态下偏转不超过 x 22°、y 28°，不会侧对读者。
  - 指针或手指靠近（300px 内）时转向它，离开时回到静止角度。
  - 学习伙伴在想时像风车一样转动；记下东西或回答记录完成时前进一格花瓣。
  - 没有任何变化时它不动。
- **B3 手机停靠**：banner 可见时吉祥物随 banner 滚动；banner 滚到顶栏下方时，缩小并停进顶栏右侧，往回滚时回到 banner。
- **B4 实现约束**
  - three.js 渲染，只在需要时绘制；生产中懒加载，在空闲时初始化，不进首屏关键路径，也不在任何交互的那一帧初始化。
  - WebGL 不可用、只有软件渲染（如 SwiftShader）、开启减少动态效果，或设备性能不足时，退回同一朵花的静态图。
  - 依据：软件 WebGL 下，原型的玻璃花会让合成卡住 9–16 秒、首次初始化卡住约 3 秒（scorecard §4.3）。验收须包含一次无 GPU 加速的测量。
  - 吉祥物始终 `aria-hidden`，不承载信息；它表达的状态在文字里都有（如“在想…”）。
- **B5 logo**：二维编织方块（两根经线、三根纬线，中间一根是珊瑚色），与吉祥物分开使用。品牌位、图标与 favicon 用 logo，不用吉祥物。
- **B6 未完成**：当前花朵模型偏灰，表面有褶皱，缩到 22px 停靠时辨识度不足。需要第二轮建模（更清透的玻璃、更顺的表面、小尺寸可辨认），
  在 YUK-1354 之前或其中完成，见 §11。

## 8. Token（T）

### 8.1 保留与替换

对照对象是 `docs/design/loom-refresh/project/tokens.css`；暗色一行对照现役 `web/src/globals.css`。

| Loom 现状 | 决定 | 新 token |
| --- | --- | --- |
| 暖纸 `--paper #FAF9F5`、暖墨 `--ink #1F1E1D` | **保留**为色阶两端 | `--gray-50` / `--gray-900` |
| `--paper*` 4 个、`--ink*` 5 个、`--line*` 3 个，零散 | **替换**为 11 级暖中性色阶 + 语义别名 | `--gray-50…900`；`--bg` `--bg-raised` `--bg-sunk` `--bg-hover` `--line` `--line-strong` `--text…--text-4` |
| `--ink-4 #8A8880`（在页面底上约 3.4:1，不达 AA） | **替换** | `--text-4` 亮 `#6B675F`（5.34:1），暗 `#959188` |
| 珊瑚 `--coral #D97757`，唯一强调色 | **保留** | `--coral-500` → `--accent` |
| `--coral-hover #C2553A` 作按钮底（白字 4.51:1） | **替换**，留出余量 | `--coral-600 #B04C2C` → `--accent-strong`（白字 5.36:1）；焦点环也用它 |
| FSRS `again/hard/good` 四件套 | **保留含义**，改名为状态色 | `--critical` `--caution` `--positive`（各带 `-soft`） |
| `--info` 蓝（AI 归属色） | **移除**；AI 与系统归属改用标签与来源标记 | — |
| 字号 11 档（13–48） | **替换**为 6 档 | `--fs-1…6` = 13 / 15 / 17 / 20 / 26 / 34 |
| 4px 网格 12 档 | **保留网格，收为 8 档** | `--sp-1…8` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 圆角 4 档 + pill | **替换**为 3 档 | `--r-1 8px`、`--r-2 14px`、`--r-3 999px` |
| 阴影 3 档 + inset + focus | **替换**：卡片不投影，阴影只给浮层与玻璃 | `--shadow-float`；玻璃材质见 T3 |
| 动效 120 / 200 / 320ms | **替换**为反馈、界面、面板三档与两条曲线 | 见 T4 |
| 现役暗色 `#1a1612`，偏褐 | **替换**为暖炭灰阶 | `[data-theme="dark"]` 同名 token；外框 `#111010`、主框 `#1a1918` |
| Google Fonts CDN | **替换**为自托管 | `@font-face` |

完整取值见原型的 `tokens.css` 与 `app.css` 顶部；YUK-1354 以此为起点落地生产 token。

### 8.2 规则

- **T1** 组件只引用语义 token：`--bg*` `--text*` `--line*` `--accent*`、状态色、尺寸、层级与动效 token。色阶原值只出现在 token 文件。
- **T2** 新设计系统在独立作用域落地（独立 CSS layer 或根属性作用域），供 TanStack Start 前门（`server/start/`）下重写的页面使用；
  不复制、不继承 `web/src/globals.css`。
- **T3 玻璃只给浮层**：命令面板、选区气泡、提示条、手机标签栏、手机记录表单。
  材质为 64% 的 raised 底加 `backdrop-filter: blur(22px) saturate(1.8)`，内侧一道高光与一圈细线，外侧柔和投影；暗色降低高光。
  正文、卡片、侧栏、学习伙伴侧栏不用玻璃。不支持 `backdrop-filter` 时退回不透明的 raised 底。
- **T4 动效 token**
  - 曲线两条：`--spring`（`cubic-bezier(0.32, 1.28, 0.48, 1)`，略带回弹）与 `--glide`（`cubic-bezier(0.22, 1, 0.36, 1)`）。
  - 时长三档：反馈 ≤ 100ms、界面 `--t-ui` 280ms、面板 `--t-panel` 420ms。
  - 吉祥物、手机抽屉等用 JS 阻尼弹簧（刚度约 190–240、阻尼约 23–29），保留速度，可被新目标打断。
  - 这比准备计划 §6 的“150–250ms”更长，属于**有意偏离**：大面积的面板与形变在 250ms 内完成显得急促，而所有过渡都可以打断，
    不会阻塞下一步操作。小元素（按钮、芯片、计数）仍按 150–250ms。是否成立以真机录屏和 M12 的指标为准。
- **T5** 所有文本 token 在 `--bg`、`--bg-raised`、`--bg-sunk`、`--bg-hover` 上 ≥ 4.5:1（禁用文字除外），亮暗两套都满足；焦点环对页面底 ≥ 3:1。
  玻璃上的文字以其最不利的背景计算对比度。
- **T6** 主题默认跟随系统（`prefers-color-scheme`），用户显式选择后才持久化覆盖。
- **T7** 层级使用命名 token：吉祥物 3 / 选区气泡 4 / 手机抽屉 40 / 标签栏 42 / 记录表单 45 / 命令面板 50 / 提示条 60。组件不写裸 z-index。
- **T8** 断点是共享常量，生产中以共享 TS 常量或 custom media 提供。原型只有 phone ≤ 720 一个断点；中等宽度下学习伙伴是否改为覆盖式尚未决定（§11）。
- **T9** 新 token 不得与 Tailwind v4 的主题命名空间同名（`--tracking-*`、`--ease-*`、`--text-*`、`--radius-*`、`--shadow-*`、`--spacing` 等），
  除非有意通过 `@theme` 映射。原型里的 `--text-*` 在生产落地时须加前缀或映射。
- **T10** 原型里仍有尺寸字面量（芯片高、状态点、图标、吉祥物位尺寸、抽屉停靠偏移等），生产中须收进 token 或共享常量。

## 9. 动效与交互（M）

### 9.1 原则

- **M1 只在变化时动**：没有用户动作或数据变化时，页面上没有任何东西在动（包括吉祥物与背景）。
- **M2 每个动画回答一个问题**：这个东西从哪来、到哪去、算不算数。回答不了的动画不做。
- **M3 可以打断**：任何过渡进行中都可以被新的操作接管——从当前位置和速度继续走向新目标，不先跳到终点，也不留下残影或隐藏的元素。
  `prefers-reduced-motion` 下所有过渡直接切换，程序滚动改为瞬时。

### 9.2 连续动画

- **M4 共享标题形变**：从“继续你的”卡片或资料的一行进入详情时，那个标题从原位置移动、放大成详情页 banner 的标题；旧标题沿同一路径淡出，
  页面其余部分只淡入，不位移。返回时沿原路收回。连续快速切换会取消上一次飞行。
  原型在提交阶段测量新页面的标题位置，会迫使整页同步排版；4× 降速下这是切屏最慢的部分（scorecard §4.3）。生产中优先用 View Transitions API，
  或把测量推迟到新页面首帧之后。
- **M5 收进去**：记下的内容沿弧线飞进“收进来的”（手机上是“记一下”按钮），落地时计数滚动加一、入口轻轻弹一下。
  撤销时计数滚回；飞行途中撤销不计数。
- **M6 引用飞入与回跳**：选中的段落离开正文，落成对话里的引用（目标在移动时，比如面板正在打开，也逐帧追踪落点）。
  引用、步骤引用与页边标记之间可以来回跳转，目标处亮一下（约 1.6s 淡出）。
- **M7 保持阅读位置**：学习伙伴开合、侧栏折叠导致正文重排时，把阅读线上的那一段固定在原处；滚轮、触摸或按键立即把控制权交还给读者。
  页面已经滚到底、无法保持时不强求。
- **M8 布局过渡**：侧栏与学习伙伴的宽度变化在原型里是 `grid-template-columns` 过渡，会逐帧重排，**不符合**“只动 transform/opacity”。
  生产中先在真机上量 Long Animation Frame；不达标时改为面板用 transform 滑入、正文只重排一次（配合 M7）。
- **M9 小的连续性**：计数滚动（变大向上、变小向下）；分段切换的墨块滑动；展开用 0fr → 1fr 的高度过渡；新条目先撑开自己的空间再出现，不一帧推挤下方内容。

### 9.3 基线

- **M10 乐观写入**：推迟、加入、记下等写操作立即生效，并给 4.5 秒撤销；失败时恢复原状并说明原因。
- **M11 反馈**：任何点击或按键在 100ms 内有可见反馈（悬停、按下颜色与按下缩放）。
- **M12 性能门槛与测量**
  - 门槛：INP < 200ms、CLS < 0.05、关键过渡流畅。“流畅”的判定：在**有头浏览器或真机**上录 Chrome trace，
    关键过渡期间没有超过 50ms 的 Long Animation Frame，且掉帧率 < 5%。每张 UI 票附真实操作录屏与上述指标。
  - headless 下 rAF 空闲时就有约 27ms 的间隔，**不能证明 60fps**。
  - 测量对象必须是生产构建，不是开发服务器。
  - 原型实测（scorecard §4）：CLS 通过；INP 在 1× 下通过，在 4× 降速下触线（200–216ms，切屏）。
- **M13 预取**：继续入口在悬停或聚焦时预取详情（TanStack `preload="intent"`）；公式等昂贵渲染前移到服务端或空闲时，不在切屏那一帧同步渲染。
- **M14 三态**：每个区域都设计载入（与布局一致的骨架，骨架到内容原位淡入）、空（带进入动作）、出错（区域隔离、可重试、已保存的工作不受影响）。
- **M15 提示条**：玻璃提示条不压住底部固定元素；手机上位于标签栏之上，文字不换行成竖排。撤销按钮的触控目标不小于 44px（原型为 30px，未达标，生产须修正）。

接入路线沿用准备计划：按路由逐条切换，每条路由保留回退开关；每一波先合后端缺口的票，再合 UI 票。

1. **设计系统与外壳**（YUK-1354）：token、基础组件、侧栏与主框、学习伙伴侧栏位、手机标签栏与抽屉、弹簧与形变工具、吉祥物（含静态退回），
   落在 TanStack Start 前门（`server/start/`），tracer 路由 `/mistakes`。
2. **回来时与系统为我做了什么**：以只读为主，接口基本具备，风险最低。
3. **资料、题目、笔记**：先补“系统目前的理解”与步骤锚点的后端票。
4. **学习伙伴替换 CopilotDock**：会话恢复、流式、提议确认、上下文与引用，最复杂，放在最后。
5. **快速记录接入 ingestion**，加上三种意图。
